# tyme-legal

Public terms of use and privacy policy for **Tyme**, Datavyne, Inc.'s internal
time-tracking and payment application, published with GitHub Pages:

- Terms: https://datavyne-llc.github.io/tyme-legal/terms/
- Privacy: https://datavyne-llc.github.io/tyme-legal/privacy/

The application's code is private; this repository holds only these pages.
To update a page, edit `terms.md` or `privacy.md` and change its effective
date.
